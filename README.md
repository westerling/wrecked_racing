# Wrecked Racing
A low poly car combat racing game.

## What is wrecked racing
Wrecked racing is an (up to) four player racing game where all players share the same camera and screen.<br/>
It is deeply inspired by one of the best forgotten party games ever made. Mashed!<br/><br/> Endless hours of mashed have been played in sofas all around the world.
The basic idea is the same.

## My project
So far this is a work in process. I am a single developer with no professional skill of either modelling or game design.<br/>
All I make is entirely for fun.<br/><br/>
